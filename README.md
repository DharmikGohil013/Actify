# 🚀 Actify

**Actify – My Tasks** is a personal task and productivity manager, built with a sleek and modern frontend. It allows users to manage their tasks, reminders, and daily productivity in a beautiful interface.

🌐 Live Demo: [https://actify.dharmikgohil.fun](http://actify.dharmikgohil.fun)

---

## 📌 Features

- Task and Reminder management
- Elegant, responsive UI
- Smart notifications
- Daily productivity booster
- Built for performance and ease of use
